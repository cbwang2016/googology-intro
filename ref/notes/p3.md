## 0. The big motivation (why Part III exists)

- In Part II, adding the **first non-recursive ordinal Ω** (第一个非递归序数, = ω₁^CK, the Church–Kleene ordinal) to an OCF (ordinal collapsing function, 序数折叠函数) let ψ get past the ζ₀ / Γ₀ / BHO barriers. Ω works because it **cannot be reached from below by any recursive process** (its "recursive cofinality" is Ω itself). So it can stand for "all the recursive operations below me". Adding Ω₂, Ω₃, …, Ω_ω reaches BO = ψ(Ω_ω), and Ω-subscript fixed points reach EBO.
- Ch9 opening (p.301): "Ω is only the smallest non-recursive ordinal. If we fully exploit the huge potential of non-recursive ordinals, we can get much bigger recursive ordinals." Each new kind of non-recursive ordinal has a stronger **closure / reflection property**. Placed inside ψ, it **collapses (折叠)** every arbitrary-depth iteration of the weaker operation below it. That pushes ψ's recursive output further.
- The book's central slogan, written `X ⇒ (Y−)^α`: "X folds/collapses arbitrary-depth Y". For example `2 ⇒ (1−)^α` means Π₂ (admissibles) collapse every recursive depth of Π₁ (limit-taking). `2 1−2 ⇒ (1−)^α 2` means I collapses every Ω-fixed-point construction.
- The pattern repeats one level up: **Ω collapses α↦ω^α, I collapses α↦Ω_α, I(1,0) collapses α↦I_α, M collapses the I-function**, and so on (p.314).
- Chapters 7–8 supply the language for this: sets, ordinals as sets, the hierarchies V and L, first-order formulas, and the Σₙ/Πₙ quantifier hierarchy.

## 1. Section-by-section summary (book order)

### Ch7 *集合与序数 Sets and ordinals (p.257–280)
- **7.1 集合与公理化体系 Sets and axiomatization.** Cantor's naive set (确定性 definiteness, 可区分 distinctness). **Russell paradox** (罗素悖论) B={A | A∉A} and the barber version. Euclid's axioms and postulates. The parallel postulate leads to Lobachevsky and Riemann geometry. The lesson: an axiom system only needs to be consistent (无矛盾), not "true of reality". This motivates axiomatizing set theory as **ZF / ZFC**.
- **7.2 公理化集合论 Axiomatic set theory.** One primitive notion (set) and two relations (∈, =), written in first-order logic. Axioms covered:
  - existence of a set
  - 外延 extensionality
  - 内涵/分离公理模式 separation schema, which avoids Russell's paradox because you may only carve a subset out of an existing set
  - 空集 empty set (a theorem)
  - 无序对 pairing; ordered pair (A,B)={A,{A,B}}
  - 并集 union; 交集 intersection (a theorem)
  - 幂集 power set
- **7.3 关系与映射 Relations and maps.** Cartesian product, relations as subsets, domain/range, functions, injective, surjective and bijective maps, restriction, image, equivalence relations and partitions.
- **7.4 自然数 Natural numbers.** Successor A′=A∪{A}; 0=∅, 1={∅}, …. The **axiom of infinity** (无限公理) gives the set ω. The Peano properties, including induction. Recursion theorem. +, ×, ^ defined by recursion. The Baire space ω^ω, and reals via continued fractions. A footnote says the induction in Peano's theorem is second-order. Inside ZFC we work with a first-order ω.
- **7.5 势与基数 Cardinality and cardinals.**
  - Equinumerosity via bijections (handing out exam papers); the Cantor–Bernstein theorem.
  - **Hilbert's hotel**: "the whole equals a part"; ℵ₀ + ℵ₀ = ℵ₀; ℵ₀·ℵ₀ = ℵ₀ via the triangular pairing.
  - Cantor's diagonal argument: |ω| < |2^ω| = |P(ω)|.
  - **CH / GCH** (连续统假设). Gödel (1940) and Cohen (1963) showed them independent of ZFC.
  - The ℶ numbers.
  - Warning: ℵ₀ is not "a number after all the finite numbers".
- **7.6 序关系 Order relations.** Partial order, total (linear) order, **well-order (良序)**: every subset has a least element. Order isomorphism, order type (序型), initial segment (前段). Any two well-orders are comparable (Thm 7.11).
- **7.7 序数 Ordinals.**
  - Finite order type = natural number.
  - Infinite well-orders with equal cardinality can have different types, e.g. {0,½,¾,…} vs that set plus {1}.
  - **Def 7.33–7.34: a transitive set (传递集) well-ordered by ∈ is an ordinal.** Every well-order is isomorphic to exactly one ordinal.
  - Successor α∪{α}; sup = union of a set of ordinals.
  - Ordinal +, ·, ^ (non-commutative: 1+ω=ω≠ω+1).
  - **Replacement schema (替换公理模式)** is needed even to form {ω, ω+1, …}, hence ω·2, ω², ω^ω, ε₀. All of these are countable.
  - Transfinite induction.
  - A cardinal is the least ordinal of its size; ℵ_α = ω_α.
  - **Axiom of choice**, the well-ordering theorem, Zorn's lemma; Banach–Tarski.
  - **Cardinal vs ordinal arithmetic differ.** For example 2^ω = ω as ordinals but 2^ℵ₀ > ℵ₀ as cardinals. "In googology we basically only care about ordinal arithmetic."
- **7.8 良基集 Well-founded sets.** The **axiom of regularity/foundation (正则公理)**: no infinite ∈-descending chains and no x∈x. Well-founded relations; the **Mostowski collapse** (折叠定理, Thm 7.24): a well-founded extensional set-like relation is isomorphic to a transitive set with ∈. The **cumulative hierarchy**: V₀=∅, V_{α+1}=P(V_α), unions at limits; V = ⋃V_α. The Cantor and Burali–Forti paradoxes, so V and Ord are **proper classes (真类)** (NBG).

### Ch8 *形式逻辑 Formal logic (p.281–300)
- **8.1 The pq-system** (Hofstadter's toy system): legal strings, axioms, inference rules, theorems. A formal system is a "word game". Its **interpretation (解释)**: p is read as +, q as =. Truth and theoremhood are different notions.
- **8.2 命题逻辑 Propositional logic L.**
  - Connectives ¬ and →, three axiom schemas, modus ponens (假言推理).
  - The proof of ⊢p→p; deduction theorem; reductio.
  - ∨, ∧, ↔ as defined symbols; truth tables.
  - **Soundness and completeness** (Γ⊢p ⇔ Γ⊨p).
  - Decidable via truth tables.
  - Intuitionism rejects excluded middle.
- **8.3 一阶谓词逻辑 First-order predicate logic K.**
  - Terms, atomic formulas, ∀ and ∃, free/bound variables, axioms 4–6, generalization.
  - **Δ₀, Σₙ, Πₙ formulas** (Def 8.16–8.17). Δ₀ means only bounded quantifiers (∃x∈y, ∀x∈y). Σₙ₊₁ = ∃…(Πₙ); Πₙ₊₁ = ∀…(Σₙ). This is the hierarchy used by every reflection and stability definition later.
  - Structures and satisfaction (A,s)⊨φ; models of set theories (A,∈)⊨M.
  - **Gödel completeness**, **compactness**, **Löwenheim–Skolem**: a consistent countable theory has a countable model.
- **8.4 一阶形式算术系统 First-order arithmetic.** Equality axioms; the **Peano axioms PA**; standard and non-standard models. Gödel numbering, representability of recursive functions, the fixed-point (diagonal) lemma, **Gödel's first incompleteness theorem**, Gödel–Rosser, undecidability of validity, **Gödel's second incompleteness theorem** (Con(T) is unprovable in T). Pointer: "natural" independent statements produce huge functions (Part VI).

### Ch9 反射折叠记号 Reflection collapsing notation (p.301–323)
- **Opening caveats (p.301).** These are very important for "rigor vs informal".
  - Rigorous set-theoretic reflection OCFs behave in an extremely complicated way, "currently hard for googology to understand".
  - The community's reflection behaviour "actually contains errors". It is "too shallow and arbitrary" and does not capture true reflection.
  - What googologists use are only recursive notations that "look like" reflection OCFs. They should be called **Ordinal Collapsing Notations (OCN, 序数折叠记号)**, not OCFs.
  - Apart from major milestones, almost everyone's details differ, by more than the MOCF-vs-BOCF difference. Almost nobody publishes full rules, and analyses are "mostly guesswork". The notation can be seen as "merely an enumeration of important nodes".
  - The book follows **梅天狸 (Mei Tianli)'s** reflection scheme and keeps only the main behaviour.
  - The rigorous proof-theoretic versions are in the later "证明论记号" chapter.
- **9.1 *可构造宇宙 Constructible universe L.** Def(A) = subsets of A first-order definable over (A,∈). L₀=∅, L_{α+1}=Def(L_α), unions at limits; L=⋃L_α. Facts: α⊂L_α and L_α∩Ord=α; V_ω=L_ω. **V=L is independent of ZFC.**
- **9.2 *反射序数的定义 Definition of reflecting ordinals.** Ordinals defined "by property, not built bottom-up". This is like ω and Ω, which were also defined by property (see §2).
- **9.3 反射操作 Reflection operations** (notation):
  - `n−X` = "Πₙ onto X" = the set of Πₙ-reflecting ordinals on X. A bare `n` means n−Ord.
  - A space means intersection: `X Y = X∩Y`. Onto and intersection are **right-associative**: `2 1−2 = 2∩(1−2)`.
  - `(φ−)^α X` means apply the operation α times. Limit α is subtle (psd/real, below).
  - `αth X`, written 1st/2nd/3rd: the α-th element. A bare `X` means min X.
  - `X aft α`: the first element of X above α.
- **9.4 递归序数与容许序数 Recursive and admissible ordinals.**
  - Π₁ = limit ordinals {ω, ω2, …}. `2nd 1 = 1 aft 1 = ω·2`. `1−1 = ω²`, `(1−)^n 1 = ω^{n+1}`, `(1−)^ω = ω^ω`, `(1−)^{(1−)(1)1} = ω^{ω^ω}`, `(1−)^{(1,0)} = ε₀` (fixed point of α↦(1−)^α), `(1−)^{(1,0,0)} = Γ₀`. "We are re-walking the Veblen journey."
  - Arbitrary-depth Π₁ reflection `(1−)^α` in principle expresses **all recursive ordinals**, and still never reaches the next level.
  - Π₂ = admissibles {Ω, Ω₂, …, Ω_{ω+1}, …}, but **not Ω_ω**, which is a limit of admissibles reached recursively. min Π₂ = Ω. Π₂ collapses every (Π₁−)^α.
  - `1−2` = limit points of the admissibles = {Ω_ω, Ω_{ω·2}, …}, like irrationals as limits of rationals. Then `(1−)^{(2)}2 = Ω_Ω` and `(1−)^{(1,0)}2 = Ω_{Ω_{…}} = Ω_{1,0}`, the fixed point of α↦(1−)^α 2.
- **9.5 递归不可达序数 Recursively inaccessible I.**
  - Question: is some ordinal both admissible (in Π₂) and a limit of admissibles (in 1−2)? It seems paradoxical, but ZFC proves it exists. `2 1−2 = Π₂∩(Π₁ onto Π₂) = {I, I₂, I_{ω+1}, …}`.
  - The name means "cannot be reached recursively". It is the recursive analogue of the **inaccessible cardinal**, and is itself non-recursive.
  - `(2 1−)` = "take admissible points (容许点)". `2 1−2 ⇒ (1−)^α 2`.
  - Then: `2 aft I = Ω_{I+1}`, `1−2 1−2 = I_ω`, `(1−)^{(2 1−2)} 2 1−2 = I_I`, …, `(2 1−)^2 2 = I(1,0)`, `(2 1−)^3 2 = I(2,0)`.
  - **Pseudo vs real reflection (伪反射 psd vs 真反射 real)** at limit depths:
    - psd.(2 1−)^ω 2 = sup = I(ω,0). This is not even admissible.
    - real.(2 1−)^ω 2 = ⋂ₙ(2 1−)ⁿ2 = I(ω+1,0). The two differ by one admissible-point step.
    - The community uses psd by default, as a pure notation.
  - The multivariable I-function behaves like Veblen φ, **with "fixed-point carry" replaced by "admissible-point carry" (容许点进位)**. The superscript follows a "weak Veblen function" convention (φ(S,α+1)=φ(S,α)+1), which catches up with ordinary Veblen at BHO.
  - I(1@ω) is not admissible; I(1@(1,0)) is.
- **9.6 含I的OCF OCFs with I.**
  - Full notation: ψ_ν outputs ν-level ordinals, e.g. ψ_{Ω_ν}. "Collapsing" in an OCF = replacing a stuck lower reflection ordinal by a higher one that behaves the same inside ψ.
  - **In BOCF:** ψ(Π₂) = ψ((Π₁−)^{(1,0)}), i.e. ψ(Ω) = ψ(ε₀). And ψ(I) = ψ(Ω_{Ω_{…}}) = **EBO**. So I's output in BOCF equals the Ω-fixed point's, even though I is vastly larger.
  - **In MOCF:** ψ(Ω_{Ω…}) = ψ(ψ_I(0)) = EBO, and **ψ(I) = ψ(ψ_I(ψ_I(…)))**, which is bigger.
  - ψ_I(α) = the (α+1)-th fixed point of β↦Ω_β. Φ-function = "Veblen for Ω-subscripts": ψ_I(I)=Φ(2,0), ψ_I(I^I)=Φ(1,0,0), …, ψ_I(ε_{I+1}) = ψ_{Ω_{I+1}}(0).
  - Expansion rule ψ(#∗I) = ψ(#∗ψ_I(#∗ψ_I(…))). **Jäger's ordinal JO = ψ(ψ_{Ω_{I+1}}(0))**. Then Ω_{I+1}, …, ψ_{I₂}(0) and I₂.
  - Thm 9.4 gives the rules for ψ_{I_α}: "I_α finds ψ_{I_α} to expand and fills layers" (补层).
  - Key intuition (p.314): admissible point = "from below, reaching it recursively needs at least as many steps as itself". Ω_α = (1+α)th 2; I_α = (1+α)th 2 1−2; I(1,0) = 2 1−(2 1−2).
  - Then ψ(I(1,0)), ψ(I(2,0)), ψ(I(1,0,0)), ψ(I(1@ω)), ψ(I(1@(1,0))). **Small Rathjen ordinal SRO = ψ(I(1@(1@(…))))**, the limit of the I-function. Part IV writes SRO = ψ(ε_{M+1}).
- **9.7 递归Mahlo序数 Recursively Mahlo M.**
  - `2−2 = M` (Π₂ onto Π₂). Analogue of the **Mahlo cardinal**; non-recursive. `2−2 ⇒ (2 1−)^α 2`: M collapses every depth of admissible points.
  - Then Ω_{M+1}, I_{M+1}, M₂, M_ω, M_M, M(1,0), …
  - **Mahlo point (Mahlo点)** `2−2 1−`, written with a semicolon: M(1;0) = 2−2 1−2−2 is both recursively Mahlo and recursively inaccessible (in the sense of 1−2−2).
  - Hierarchy of collapse: **admissible point 2 1− ⇒ (1−)^α (fixed points)**; **Mahlo point 2−2 1− ⇒ (2 1−)^α**.
  - Naming at this level is **not unified**, e.g. M−φ(1,0), M−I(1,0), M−M(1,0).
- **9.8 Π₂反射序数 Π₂ reflection iterated.**
  - `2−2−2 = N` (book: 不可转换序数). It collapses arbitrary-depth Mahlo points: `2−2−2 ⇒ (2−2 1−)^α 2−2`.
  - General rule: **`2−X ⇒ (X 1−)^α`** and `(2−)^n 1−X ⇒ ((2−)^{n−1} 1−)^α X`.
  - **psd/real trouble at (2−)^ω.** psd.(2−)^ω = sup{Ω,M,N,…} is not admissible. "2−psd.(2−)^ω = 2∩psd.(2−)^ω" is not even recursively Mahlo. real.(2−)^ω collapses every depth of psd.(2−)^ω.
  - Yet "formally" the community sets real = psd+1. "It no longer corresponds to the mathematical reflection ordinal, but as a notation the simplification causes no trouble."
- **9.9 Π₃反射序数 Π₃ reflection.**
  - `3 ⇒ (2−)^α`. **min Π₃ = K = recursively weakly compact** (递归弱紧致, analogue of the **weakly compact cardinal**).
  - 1−3 = K_ω. "K point" `3 1−`: `3 1−3 ⇒ (2−)^α 1−3`. Then 2−3, 3 2−3 ⇒ (2−)^α 3, 3−3 ⇒ (3 2−)^α 3, … up to psd.(3−)^ω.
  - "At this level even the non-recursive notations cannot be unified", so only pure reflection expressions are used.
- **9.10 反射的折叠规律 General collapse rule (Thm 9.5).**
  - Rule: for a sequence `a_k #1 a_i #2`, let a_i be the first term to the right of a_k that is smaller than a_k. Pad with a_k−1 if needed. Then **`a_k #1 (a_k−1) #2 ⇒ (#1 (a_k−1))^α #2`**.
  - Strip the `−` and space operators (− when increasing, space when decreasing) and reverse the order. The rule then becomes exactly the **primitive sequence (初等序列, PrSS) expansion**. Example: `2−3 1−3 2−3` becomes 3,2,3,1,3,2, which expands to (3 1−)^α 3 2−3.
  - "The similarity comes from the ε₀ tree structure of reflection ordinals themselves."
- **9.11 更高的反射序数 Higher reflection.**
  - Π₄ ⇒ (3−)^α 3 (full list of examples), Π₅, Π₆, …
  - **psd.Πω = sup Πₙ; real.Πω = ⋂ₙ Πₙ**, which collapses (psd.Πω−)^α.
  - **Small Stegert ordinal SSO = ψ(Πω)**: the limit of finite-order reflection notation. Part IV writes SSO = ψ(psd.Πω) = BMS (0,0,0)(1,1,1)(2,2,0) (see §4).
  - Π_α, Π_{Π_α}, Π_{(1,0)} give only limited strength; "naive reflection notation has basically reached its end".
  - Beyond Mahlo, community reflection notations "have no written method at all; almost entirely guesses and estimates". Pointers to large comparison tables [989-1003].
  - **Stegert (2011)** first gave a rigorous Πω-reflection OCF, which is the source of the name ψ(Πω). It is far beyond community understanding.
  - Nevertheless, "values at important nodes are basically unified … cross-validated, now basically reliable".

### Ch10 稳定折叠记号 Stability collapsing notation (p.325–335)
- **Opening:** stability is stronger than reflection and has deep set-theoretic content, but it can be used formally. **The notation is not unified, and how to properly put stable ordinals into an OCF is still unknown.**
- **10.1 *Σ₁稳定 Σ₁ stability.**
  - Intuition: map a bigger structure onto a smaller one so that certain properties of the big one still hold in the small one. The smaller one then "keeps the information" of the bigger one. The closer the two structures are, the easier this is. The more information you demand, the harder.
  - Def 10.1–10.2 (see §2). Thm 10.1 lists closure facts.
  - HypCos notation λα.f(α), inspired by λ-calculus. λα.α is trivial.
  - **Thm 10.2: if α is (α+1)-stable then α is Πₙ-reflecting for every n; λα.(α+1) = real.Πω.** "Just raising the stability target by 1 already exceeds all the reflection ordinals discussed before."
- **10.2 稳定记号 Stability notation.**
  - `λα.f(α)−Πₙ`, with stability target (稳定目标) f(α) and iteration counter (迭代计数器) Πₙ. **"No strict mathematical definition; the community only explains its behaviour."**
  - −Π₁ = the real stable ordinal; −Π₀ = its psd version (a sup).
  - `λα.f(α)−Πₙ₊₁ ⇒ (λα.f(α)−Πₙ)^{Ω_{α+1}}`, i.e. collapse to "all depths below the next non-recursive ordinal".
  - Examples: λα.(α+1)−Π₀ = psd.Πω; −Π₁ = real.Πω; −Π₂ = Π_{ω+1}; −Π₃ = Π_{ω+2}; λα.(α+2)−Π₀ = psd.Π_{ω·2}.
  - General: sup over counters raises the target by 1 (10.12–10.13).
- **10.3 递归稳定目标 Recursive stability targets.**
  - Above psd.Πω the whole reflection hierarchy is re-walked (1−psd.Πω, 2 1−psd.Πω, …).
  - λα.(α+1+β)−Π₁ = real.Π_{ω·β}, so λα.(α+ω)−Π₁ = real.Π_{ω²}, with "catch-up" (追平) at ω^ω. Targets ε₀, Ω, I, M, K, and Πω itself appear as subscripts: real.Π_I, Π_M, Π_K, Π_{Πω}, …
  - **λα.(α·2)−Π₁ = real.Π_{1,0}**, the fixed point of β↦Π_β.
  - Then α·3, α·ω, α·Ω, α², α^α, α^{α^α}, … Rule (10.70): `λα.(#∗α)−Π₀ = fixed point of β↦λβ.(#∗β)−Π₁`, for ∗ ∈ {+,·,^}.
  - General recursive targets have no general rule; they are handled case by case, which matters little after OCF collapse.
  - **λα.Ω_{α+1}−Π₁ stabilizes α to its next admissible and surpasses every recursive target f(α).**
- **10.4 *非Gandy现象 The non-Gandy phenomenon.** See §2 for the definitions.
  - Until now "non-recursive" and "admissible" were silently identified. They diverge at λα.Ω_{α+1}.
  - Googology writes Ω_α for the α-th **non-recursive** ordinal and ω^CK_α for the α-th **admissible**.
  - **pfec stability** (parameter-free effective cardinal; uses non-recursive Ω_α, i.e. ignores non-Gandy) vs **adm stability** (admissible-based, rigorous). pfec is much weaker. Adm's strength is not clearly understood, so the book uses only pfec.
- **10.5 单段稳定 Single-segment stability.**
  - When the target is admissible (e.g. Ω_{α+1}) there is no recursive ω-cofinal sequence. So only the real version exists: write λα.Ω_{α+1}−Π₁, never −Π₀.
  - Then λα.Ω_{α+1}−Π₂, −Π₃, …, λα.(Ω_{α+1}+1)−Π₀, …, λα.Ω_{α+2}−Π₁, λα.Ω_{α+3}−Π₁, …
  - **Small Dropping ordinal SDO = ψ(λα.Ω_{α+ω}−Π₀)**, the limit of "Dropping"-type notations.
  - Then Ω_{α·2}, Ω_{α^α}, …, λα.Ω_{Ω_{α+1}}−Π₁, and targets "α aft I" = I_{α+1}, M_{α+1}, K_{α+1}, α aft Π₄, α aft psd.Πω, α aft real.Πω.
- **10.6 稳定链 Stable chains.**
  - λα.(α aft real.Πω)−Π₁ = λα.(α aft λβ.(β+1)−Π₁)−Π₁ is a **two-step chain α → β → β+1**: β stabilizes to β+1, and α stabilizes to the next such β.
  - Grow the inner target, then the three-chain α→β→γ→γ+1, four-chain, and so on.
  - Sup of finite chains = **ω−π−Π₀**. **Large Rathjen ordinal LRO = ψ(ω−π−Π₀)**.
  - "The community knows almost nothing about the details of such an OCF … we do not actually have a complete reliable stability-collapsing function; we only have estimates and guesses about big nodes."
- **10.7 *方括号稳定 Bracket stability.** HypCos's β-Γ-reflection, Γ-f-reflection, and Γ[η], β[η] stability (Def 10.7–10.9). "Complex structure but not very strong; now rarely used." Higher Σₙ stability is in Ch12.

### Ch11 投影折叠记号 Projection collapsing notation (p.337–345)
- **Opening:** powerful, and recursivizable into big recursive notations. **"It has no rigorous definition; the correspondence between its big ordinals and real ordinals in the set universe is unclear; we largely use it formally."**
- **11.1 最小的二阶投影 The least second-order projection α.**
  - First-order projection ordinals = all admissibles. Second-order projection is "very strongly non-recursive". **Conjecture: fully Σ₁-stable ordinals (L_α ≺ L) might fit.**
  - ψ_α() (BOCF style): ψ_α(0)=1; ψ_α(γ+1)=ψ_α(γ)·ω; ψ_α(#∼α) = fixed point of β↦ψ_α(#∼β), where ∼ may be **any recursive operation**.
  - **Key difference from an OCF: no "plateau" (平台期).** For a first-order projection (admissible) μ, ψ_α(μ) = sup_{ν<μ} ψ_α(ν).
  - Values (a very useful "dictionary"):
    - ψ_α(α)=ε₀, ψ_α(ε_{α+1})=BHO
    - **ψ_α(Ω_{α+1})=Ω**, ψ_α(Ω_{α+1}·2)=Ω₂, ψ_α(Ω_{α+1}·α)=ψ_I(0)
    - **ψ_α(Ω_{α+1}²)=I**, ψ_α(Ω_{α+1}³)=I(1,0), ψ_α(Ω_{α+1}^ω)=I(ω,0), ψ_α(Ω_{α+1}^{α+1})=I(1,0,0)
    - **ψ_α(Ω_{α+1}^{Ω_{α+1}})=M**, Ω_{α+1}^{Ω_{α+1}·2} → 2−2 1−2−2, Ω_{α+1}^{Ω_{α+1}²} → N = 2−2−2
    - **ψ_α(Ω_{α+1}^{Ω_{α+1}^{Ω_{α+1}}}) = Π₃ = K**, the 4-tower → Π₄, the 5-tower → Π₅
    - **ψ_α(ε_{Ω_{α+1}+1}) = psd.Πω = λα.(α+1)−Π₀; ψ_α(ε_{Ω_{α+1}·2}) = real.Πω**
    - ψ_α(ζ_{Ω_{α+1}+1}) = λα.(α+ω)−Π₀
    - ψ_α(φ(Ω_{α+1},1)) = λα.Ω_{α+1}−Π₁, ψ_α(Ω_{α+2}) = λα.Ω_{α+1}−Π₂, ψ_α(Ω_{α+ω}) = λα.Ω_{α+ω}−Π₀
    - ψ_α(I_{α+1}) = λα.I_{α+1}−Π₁, …
  - "The strength of the least second-order projection is basically that of single-segment stability."
- **11.2 完整的二阶投影 Full second-order projection.** α_n and ψ_{α_n} behave like Ω_n and ψ_n. Rules: ψ_{α_{n+1}}(0)=Ω_{α_n+1}, layer-filling (补层), and no plateau within the same level. ψ_α(ψ_{α₂}(ε_{Ω_{α₂+1}+1})) = a two-segment chain. **ψ_α(α_ω) = ω−π−Π₀**, and ψ_α(α_μ) = μ−π−Π₀ (a chain of length μ). Recursivized projection details are "not very clear".
- **11.3 有限阶投影 Finite-order projections.** The third-order β, with ψ_β(β)=ε_{α+1}, ψ_β(Ω_{β+1}²)=I_{α+1}, ψ_β(α_{β+1})=α₂, ψ_β(α_{β+1}·β)=α_{α_{…}}. This quickly exceeds second-order projection and bracket stability. General (i+1)-order rules (11.120–11.124). Sup of finite orders = ω−proj. (psd). **TSSO (Trio Sequence System Ordinal, 三行矩阵系统序数) = ψ(ω−proj.)**. (1,0)−proj. = fixed point of α↦α−proj., the limit of "regular" projection.
- **11.4 向上投影 Upward projection.** By **最菜萌新**; "currently the mainstream higher-order projection notation".
  - S = min (1,0)−proj. A raising operator σ: σΩ=α, σ²Ω=β, and σS=(1,1)−proj.
  - "Upward": S ⇒ σⁿS, i.e. S projects to ordinals of *higher* projection level than itself (min (1,n)−proj > nth (1,0)−proj).
  - ψ_S(S)=ε₀, ψ_S(σS)=Ω, ψ_S(σS·2)=α, ψ_S(σS·ω)=ω−proj., ψ_S(σS²)=(1,0)−proj.
  - S[2]=(2,0)−proj., X=(1,0,0)−proj. (operators σ, θ), A=(1@(1,0))−proj., H=(1,,0)−proj. (the "BHO" of projection).
  - 最菜萌新 also made recursivized-projection rules and a sequence notation **UPS** that simulates it. "Not yet mature; no detailed definition of recursivized projection."

### Ch12 *强非递归序数 Strongly non-recursive ordinals (p.347–356)
A literature survey of real set-theory and recursion-theory results. The theorems are cited; the OCFs for these are "still needing very deep research".
- **12.1 高阶反射 Higher-order reflection.**
  - Σ^m_n/Π^m_n formulas use (m+1)-th-order variables. π^m_n, σ^m_n, δ^m_n = the least Π/Σ/Δ^m_n-reflecting ordinal.
  - Thm 12.1: π¹₁ < σ¹₁, σ¹₂ < π¹₂, σ¹₂ = δ¹₂. Under V=L and under PD (projective determinacy) the patterns alternate (Thm 12.2–12.3, 12.11–12.13).
  - **Thm 12.4–12.7:** Π¹₀-reflecting ⇔ Πₙ-reflecting for all n ⇔ (α+1)-stable; **Π¹₁-reflecting ⇔ α⁺-stable (Ω_{α+1})**; Σ¹₁-reflecting ⇔ α ∈ λα.Ω_{α+1}−Π₂. **Least non-Gandy = σ¹₁** (Thm 12.8).
  - Closure ordinals |Πᵐₙ| of inductive definitions; δ−Πₙ reflection; **α is (α+ξ+1)-stable ⇔ ξ−Πₙ-reflecting for all n** (Thm 12.17).
  - **Reflecting ordinals are recursive analogues of indescribable cardinals** (use V_α instead of L_α).
- **12.2 高阶稳定 Higher stability.**
  - Σₙ-elementary substructure; α is β-Σₙ-stable; **fully Σₙ-stable (完全Σₙ稳定): L_α ≺_Σₙ L**; Σₙ-extendible.
  - **Least fully Σ₁-stable = least Σ¹₂-reflecting** (Thm 12.18). Its large-cardinal analogue is the **shrewd cardinal (精明基数)**; there is also "recursively shrewd".
  - **Non-projectible ordinal (不可投影序数)**: an admissible α with no α-recursive injection into a smaller β. **⇔ a limit of α-stable ordinals** = Π₁−(ω−π−Π₁) in googology notation. Analogue of the **subtle cardinal (精妙基数)**. The name "projectible" coincides with "projection notation" only by accident.
  - Non-analytic δ¹ₙ; least fully Σ₁-stable = least δ¹₂ on ω; δ_∞ = least α with L_α ≺ L_{ω₁}.
  - Open question raised by the book: can we define Σᵐₙ stability analogous to Πᵐₙ reflection?
- **12.3 高阶容许 Higher admissibility.** Σₙ-admissible (via Σₙ-cofinality over Jensen's J_κ). Σ₁-admissible ⇔ Π₂-reflecting. Characterizations via partition properties, tree and compactness properties, and filters. These are not the same as the weaker "n-admissible" (= Πₙ₊₁-reflecting) in some literature. **Higher admissibility lies below full Σ₁-stability.**
- **12.4 间隙序数 Gap ordinals.**
  - **α is a gap if (L_{α+1} − L_α) ∩ P(ω) = ∅**: no new reals are constructed at that step. The least is countable, and gaps are unbounded in ω₁.
  - "Starts a gap"; gap length. If α starts a gap that persists to β, then L_α ≺_Σ₁ L_β. Starts a Δₙ-gap ⇔ Σₙ-admissible and locally countable, so a gap start is Σ_ω-admissible.
  - Distribution theorems; higher-order (P^m(ω)) and ordinal-order gaps; generalizations.
  - The least (higher) gap ≤ least fully Σ₁-stable σ, by a Σ₁-reflection argument.
- **12.5 公理体系的模型 Models of axiom systems.** Löwenheim–Skolem means the least α with L_α ⊨ T is countable; stronger T gives stronger α.
  - **Admissible ⇔ L_α⊨KPω; rec. inaccessible ⇔ KPi; rec. Mahlo ⇔ KPM; rec. weakly compact ⇔ KPΠ₃; Πₙ (n≥2) ⇔ KPΠₙ; Π¹₀ ⇔ KPΠω.**
  - Non-projectible ⇔ KP+Σ₁-Sep ⇔ Σ¹₂-CA (on P(ω)∩L_α) ⇔ KPi + unboundedly many stables.
  - Gap ⇔ L_α ⊨ full Separation; gap start ⇔ ZFC⁻ + "every set is countable". β-models of second-order and n-th-order arithmetic.
  - **World ordinal (世界序数): L_α ⊨ ZFC** (Shepherdson–Cohen model). Large-cardinal axioms give more.
- **12.6 模型中的不可数序数 Uncountable ordinals in models.**
  - ω₁^{L_{α+1}} ≈ Σ_ω-admissible = a gap of length 1. ω₁^{L_{α+β}} ≈ a gap of length β. ω₂^{L_{α+1}} ≈ a length-ω stable chain or a 2nd-order gap (uncertain).
  - **ω₁^L**: countable if 0♯ exists. **All the reflection, stability, admissibility and gap ordinals above are L-definable countable ordinals and lie below ω₁^L.**
- **12.7 初等嵌入 Elementary embeddings.** Full elementarity ≈ "real Σ_ω stability". j: L_α→L_β, then j: L_{α+1}→L_{β+1}, …; the **critical point of a non-trivial j: L→L** needs 0♯ and ≈ an L-indiscernible. Points ahead to the "inner models" chapter.

### Intuitive pictures the book offers
- **"Limit points vs admissible points vs Mahlo points"**: three levels of "carry" (进位), as with Veblen φ.

  - Admissible point (容许点) `2 1−`: I-function.
  - Mahlo point `2−2 1−`: semicolon in M(…;…).
  - Each level collapses arbitrary iterations of the previous one.
- **Rationals and irrationals**: Ω_ω is a limit of admissibles but not admissible, "like reaching irrationals as limits of rationals" (p.307).
- **The reflection-expression ↔ primitive-sequence correspondence (Thm 9.5)**: reflection expressions carry an ε₀-tree structure, so you expand them like PrSS.
- **Stability as "information-preserving shrink"** (p.325).
- **Projection dictionary (§11.1)**: the whole reflection ladder corresponds to an ε₀-like ladder in Ω_{α+1}. I ~ Ω², I(1,0) ~ Ω³, M ~ Ω^Ω, K ~ Ω^Ω^Ω, Πω ~ ε_{Ω+1}. Pedagogically this is a great "zoom-out" picture.

## 4. Rigorous vs informal / conjectural; open problems

**Rigorous (standard mathematics, or theorems cited from the literature):**
- Ch7–8 content (ZFC basics, ordinals, cardinals, V, L, logic, completeness, compactness, Löwenheim–Skolem, Gödel's incompleteness). The book only sketches proofs and says its presentation "is still not rigorous".
- Defs 9.2, 9.5, 9.6 (L, reflection) and Thms 9.1–9.3 (Πₙ ⇔ Σₙ₊₁, Π₁ = limit points, Π₂ = admissible).
- Defs 10.1–10.2, 10.4–10.6 (Σ₁-elementarity, stability, admissibility via KPω, δ(α), Gandy). Thm 10.1, Thm 10.2 (α+1-stable ⇒ all Πₙ).
- All of Ch12: theorems with citations, some assuming V=L or PD.
- Rigorous OCFs exist in proof theory (the later "证明论记号" chapter): Rathjen-style OCFs for I/Mahlo/Π₃ levels, and **Stegert's 2011 Πω-reflection OCF**. These are rigorous but "far beyond what the community can understand".

**Informal / heuristic / known-to-be-imprecise:**
- The community **reflection collapsing notation** as a whole. The book itself says it "contains errors", is only an OCN, differs per person, has no published full rules, and is "mostly guessing". After Mahlo there is "no written method at all". Node values are considered reliable only through cross-validated tables.
- **psd vs real** conventions. "real = psd + 1" is false for (2−)^ω and Πω but is adopted as notation. The "weak Veblen" superscript convention.
- **Stability notation λα.f(α)−Πₙ**: "no strict mathematical definition". General recursive targets have no general collapse rule. **pfec instead of adm** is used deliberately; the adm version's strength is unknown.
- **No reliable stability OCF exists**; LRO and nearby nodes are "estimates and guesses".
- **Projection notation**: "no rigorous definition; correspondence to real set-theoretic ordinals unclear; used formally". Second-order projection ≈ fully Σ₁-stable is a **conjecture**. Third-order and higher have unknown set-theoretic meaning. Recursivized projection and UPS are "not mature".
- Naming is not unified, e.g. Mahlo-level M(…) variants and the ψ(I) BOCF/MOCF meanings.

**Open problems the book names or implies:**
1. **Rigorize reflection OCFs** for community use: a precise, recursive, agreed-on notation with fundamental sequences matching true Πₙ-reflection behaviour, bridging to Stegert's / Rathjen's rigorous OCFs.
2. **How to put stable ordinals into an OCF at all** (Ch10 opening). The detailed behaviour of LRO-level collapses.
3. **Adm-stability vs pfec-stability**: the strength under real admissibles (non-Gandy) is unclear.
4. **Foundations of projection notation**: which set-theoretic ordinals the 2nd/3rd/… order and upward projections correspond to; a rigorous recursivized projection; maturing UPS.
5. Ordering Πᵐₙ vs Σᵐₙ reflection in general ("difficult"); **can Σᵐₙ stability be defined analogously to Πᵐₙ reflection?** (end of 12.2).
6. OCFs able to host Ch12's strongly non-recursive ordinals ("needs very deep research").

## 5. Recommendation for a high-school learner

**Bottom line:** the learner needs the *storyline* and two or three concrete mechanisms. The set theory and logic are prerequisites only "in slogan form". Chapters 10–12 should mostly be shown as a map, with a few exact names. Do not try to teach the definitions of stability or projection rigorously. The book itself does not have rigorous versions of most of the notations.

### Prerequisites to extract from Ch7–8 (short, intuitive)
- Ordinals as "the set of all smaller ordinals". Successor vs limit; sup.
- ω, ω+1, ω·2, ω², ω^ω, ε₀ are all countable; ordinal arithmetic is not cardinal arithmetic (1+ω=ω≠ω+1; 2^ω=ω as ordinals).
- Russell's paradox and "why axioms" (one page). Hilbert's hotel and the diagonal argument (optional fun).
- V vs L as "build by all subsets" vs "build by definable subsets" (one picture).
- Quantifier counting: Σ₁ = "∃…", Π₂ = "∀∃…". Enough to read "Πₙ".
- Löwenheim–Skolem in slogan form ("a theory's smallest model can be countable"). This explains why "huge-sounding" ordinals are still countable.
- Gödel incompleteness in slogan form (optional; Part VI uses it).

### Minimal intuitive storyline (three depths)

**Depth 1: everyone (core narrative, ~1 lesson)**
1. *Problem:* recursive notations stall (ε₀, Γ₀, BHO). Trick from Part II: invent an ordinal Ω that no computation can reach, and let ψ "diagonalize over everything below Ω".
2. *Upgrade idea:* use a bigger "unreachable" ordinal whose defining property is **closure under a stronger operation**. Inside ψ, it collapses ("folds") all iterations of the weaker operation.
3. *The ladder with one sentence each:*
   - **Ω**: closed under all recursive operations.
   - **I**: an Ω that is also a limit of Ωs, i.e. closed under "next Ω" (α↦Ω_α).
   - **M**: so rich in I-like points that "any Π₂ property true at M is already true below". Collapses every I-construction.
   - **K (Π₃)**, then **Πₙ**, then **Πω**: stronger reflection.
   - **Stability**: "L_α is an exact Σ₁-miniature of L_β". Even "α is a miniature of α+1" beats all Πₙ.
   - **Chains** and **projections**: beyond that.
   - Name the recursive milestones: BO, EBO, ψ(I), JO, SRO, ψ(M), SSO, SDO, LRO, TSSO.
4. *Slogan:* "fixed point → admissible point → Mahlo point → reflection → stability → projection". Each level folds arbitrary depth of the previous one.

**Depth 2: motivated learners (~2–3 lessons, interactive)**
- **Reflection as a "mirror" definition**: L_α ⊨ φ ⇒ some smaller L_β ⊨ φ. Show Π₁ = "limit point" and Π₂ = "admissible point" concretely: Ω, Ω₂, … but not Ω_ω (rationals/irrationals picture).
- **Reflection-expression algebra** (`n−X`, intersection by space, `(φ−)^α`, `aft`, `αth`). Show the small ladder 1−1 = ω², (1−)^{(1,0)} = ε₀, 1−2 = Ω_ω, 2 1−2 = I, 2−2 = M, 3 = K.
- **Interactive widget idea:** the Thm 9.5 expansion rule ↔ primitive-sequence correspondence. Learners already know PrSS from Part II, so they can expand `2−3 1−3 2−3` by reversing it and treating it as a PrSS. This ties Part III to the "worm" notations of Part IV.
- **I-function = Veblen with admissible-point carry**: I(1,0), I(2,0), I(1,0,0) by analogy with φ. Contrast BOCF ψ(I)=EBO vs MOCF ψ(I).
- **Projection "dictionary" as a zoom-out** (no definitions): Ω ↔ Ω_{α+1}, I ↔ Ω², M ↔ Ω^Ω, K ↔ Ω^Ω^Ω, Πω ↔ ε_{Ω+1}. "The entire reflection ladder is just an ε₀-shaped staircase one level up." This is very motivating.
- Optional: Σ₁-stability via the "information-preserving shrink" picture, and λα.(α+1) = Πω.

**Depth 3: mention only, as "beyond / research frontier"**
- psd vs real reflection subtleties; Mahlo points with ";"; N; Π₃ internal structure; Πₙ expansions.
- λα.f(α)−Πₙ counters; the non-Gandy phenomenon (pfec vs adm); bracket stability.
- Stable chains in detail; 2nd/3rd/ω-order projection rules; upward projection (S, σ, θ, H); UPS.
- Ch12: higher-order reflection (Πᵐₙ), Σₙ-admissibility, gap ordinals, non-projectibles, fully Σₙ-stable, world ordinals, ω₁^L, 0♯, j: L→L. Present them as a "skyline" picture with a rough order (rows 21–27), clearly labelled "real set theory; no googology notation reaches here reliably".
- Recurring honesty message: **from Mahlo onward the notations are informal guesses validated by cross-checking; there is no community-usable rigorous OCF, and stability/projection have no rigorous definition.** Students should learn which claims are theorems (Ch7–8, Ch12 citations, Thms 9.1–9.3, 10.2) and which are community folklore.

### Suggested course placement
- One "Why we need bigger Ω's" lesson after the OCF unit. One "Reflection ladder" lesson (Depth 2, with the PrSS-expansion widget). One "Stability and beyond" overview with the skyline. Optional appendix pages for ZFC, L, and logic.
- In the bilingual UI, always pair terms, e.g. 容许序数/admissible, 递归不可达/recursively inaccessible, 递归Mahlo/recursively Mahlo, 递归弱紧致/recursively weakly compact, 反射/reflection, 稳定/stability, 稳定链/stable chain, 投影/projection, 伪反射/真反射 psd/real, 不动点/容许点/Mahlo点, 平台期/plateau, 补层/layer filling, 间隙序数/gap ordinal, 不可投影/non-projectible, 可构造宇宙/constructible universe.
